# **WanderTag**

Welcome to **WanderTag**—where the great outdoors meets digital discovery!

Embark on a journey of exploration where your passions intersect with your location. Leave virtual notes that come to life only when others venture into the same physical space. Uncover hidden gems, share your outdoor wisdom, and connect with like-minded adventurers.

## **Tech Stack**

WanderTag is built using a modern web development stack:

- **React** (with Vite) — For a fast, interactive user experience.
- **Styled-Components** — For modular and scoped CSS styling.
- **Leaflet** — Provides a beautiful, interactive map for notes and locations.
- **React-Query** — Manages remote state and data-fetching needs efficiently.
- **Zustand** — Simplifies UI state management.
